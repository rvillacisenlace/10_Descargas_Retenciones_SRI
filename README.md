# Archivist

Archivist descarga los comprobantes electrónicos recibidos desde el portal del SRI (PDF y XML) y los archiva ordenados por fecha y tipo. Proyecto hermano de Docket.

Estado: estructura inicial. Fase 0 (definición del portal) pendiente.

Reglas del repositorio: nunca versionar `.env`, `.auth/`, comprobantes, capturas ni `dist/`/`build/`.
